# 像素 UPC

在中国石油大学（华东）唐岛湾校区漫游，或从「学生手册」开始体验一个模拟学期。

## 运行

1. 在 GitHub 点击 **Code → Download ZIP**。
2. Windows 下右键 ZIP，选择 **全部解压**。在 macOS 下用 Finder 解压整个压缩包。
3. 进入解压后的 `pixel-upc-main` 文件夹，用浏览器打开其中的 `index.html`。

地图和界面需要同一文件夹内的 `style.css` 和全部 `.js` 文件。直接在压缩包内打开 `index.html` 时，浏览器可能只拿到这一个文件，显示空白地图和默认样式。游戏无需安装依赖，学生档案自动保存在当前浏览器。

- 使用 `WASD`、方向键或触屏摇杆移动。按 `E` 与附近同学或地点互动，按 `M` 打开地图。
- 学生模式包括 16 个教学周和第 17 周的期末考试。可选课、赶课、在图书馆自习，并管理生活指标。课程、教室编号、教学周安排及生活费用为游戏设定。
